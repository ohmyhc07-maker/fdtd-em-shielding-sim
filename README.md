# 원형 큐 기반 전자기파 차폐 시뮬레이터

C 언어와 raylib으로 만든 전자기파 차폐 시뮬레이터입니다.
전기장과 자기장을 각각 원형 큐에 저장하고 갱신하여,
물질에 따른 전자기파의 전파·반사·차폐 현상을 그래프로 보여줍니다.

## 파일 구성

- em_queue.c: C 소스 코드
- em_queue.exe: Windows용 실행 파일
- korean.ttf: 화면에 사용하는 한글 글꼴
- OFL.txt: 글꼴 라이선스 안내

## 실행 방법

1. ZIP 파일의 압축을 모두 풉니다.
2. em_queue.exe와 korean.ttf를 같은 폴더에 둡니다.
3. em_queue.exe를 실행합니다.
4. 콘솔의 질문에 따라 물질 번호, 두께, 주파수를 하나씩 입력합니다.
5. 그래픽 창을 클릭하고 SPACE를 눌러 재생합니다.

별도의 C 컴파일러나 raylib 설치 없이 실행하도록 빌드했습니다.
혹시 exe 파일이 실행이 안될 경우 Raylib 설치 후 c 파일로 실행해주세요.

## 입력

- 물질: 0 = 공기, 1 = 도전성 고무 모형, 2 = 구리(완전도체 근사)
- 두께: 10~120 mm 정수. 홀수는 다음 짝수로 조정됩니다.
- 펄스 중심 주파수: 0.5~3 GHz

입력 예시: 물질 1 → 두께 60 → 주파수 1

## 조작

- SPACE: 재생 / 일시정지
- R: 같은 조건으로 초기화 후 일시정지
- 창 닫기: 종료

시뮬레이션 시간 24 ns에 도달하면 자동으로 정지합니다.

## 그래프 설명

- 가로축: 공간상의 위치
- 위쪽 그래프: 전기장
- 아래쪽 그래프: 비교를 위해 Z0 × H로 환산한 자기장

그래프의 위아래 변화는 장의 부호와 크기를 나타내며,
파동이 실제로 위아래로 이동하는 궤적은 아닙니다.
